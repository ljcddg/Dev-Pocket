口袋助手 · 使用与打包指南（v1.5）
=====================================

【这一版（v1.5）改了什么】
  1. 现在显示的是「真实余额」——账户本周期还剩多少积分，不再是签到累计值。
     卡片大号数字的标签从「当前积分」改为「剩余额度」，下方小字另标「签到累计」，
     两个数字分开显示，不再混在一起。
  2. 积分详情页顶部蓝色卡片：大数字 = 剩余额度，下面一行「总计 X · 已用 Y」，
     明细里新增「签到累计获得」一行。
  3. 余额接口走的是 /billing/meter/get-user-resource-summary（注意：不带 /v2，
     与签到接口的 /v2/billing/meter/... 不是同一前缀），失败会自动回退另一种写法。
     汇总里没有明细时，自动补查免费包/付费包两份分页数据再求和。
  4. 「添加密钥」页的 API Key 输入框改成普通明文输入：看得见自己贴的是什么，
     去掉了右侧小眼睛图标，也不再被输入法自动纠错。
  5. 诊断入口升级：长按账号卡片 →「查看接口原始数据」，现在同时显示
     【签到接口】和【余额接口】两段原始返回。

  说明：余额是「还能用多少」，签到积分是「一共赚了多少」，两者不是一回事。

  5. 修复：Release 包因代码压缩（R8）导致一启动就闪退的问题 —— 已关闭压缩优化，

  · 余额 —— DeepSeek API 密钥余额查询
  · 签到 —— WorkBuddy 账号每日签到领积分
  切换方式：底部导航栏。


【登录方式（重要，先看这段）】
  WorkBuddy 登录页提供了几种渠道，但在手机 App 里只有一部分能用：

  ✅ 手机号验证码   在 App 内直接完成，推荐
  ✅ 邮箱验证码     在 App 内直接完成
  ❌ 微信登录       打开的是微信小程序，登录状态留在微信里，
                    不会带回 App，所以 App 内走不通
  ❌ 微信扫码       手机没法扫自己屏幕
  ⚠ QQ / SSO       取决于账号类型，非企业账号一般用不上

  所以点「微信登录」时 App 会拦下并弹窗说明，引导改用手机号/邮箱。
  如果坚持用微信，可以点弹窗里的「在浏览器打开」，在系统浏览器里登录
  （但登录结果同样不会自动回到 App，需要手动点「我已登录」确认）。

  登录页右上角有两个按钮：
    ✓  我已登录        手动让 App 去查一次登录结果
    ↗  在浏览器打开    把当前登录页丢到系统浏览器


【签到功能怎么用】
  1. 底部点「签到」→ 点右上角 ＋
  2. 在弹出的登录页里点「手机号」或「邮箱」，填手机号/邮箱 + 验证码登录
  3. 登录成功后自动返回，账号出现在列表里
  4. 点卡片上的「签到」领取当日积分；点右上角刷新可查最新状态
  5. 短按卡片 → 进入「积分详情」，看累计积分总额、连签奖励进度和 28 天签到日历

  支持多账号：再点一次右上角 ＋ 用另一个账号登录即可。
  长按卡片可以：刷新状态 / 重命名 / 重新登录 / 删除账号。

  如果登录页卡在「等待登录…」：
    · 把登录页切到后台再切回来，App 会自动重新检查一次
    · 或者直接点「我已登录」
    · 自动等待上限 10 分钟，超时不会关闭页面，手动检查随时可用


【技术上是怎么实现的（供你了解）】
  WorkBuddy 桌面端用的是腾讯统一账号 OAuth + 自研登录编排，App 复刻了同一套流程：
    1. POST /v2/plugin/auth/state?platform=mobile   创建登录态，拿到登录页地址
    2. WebView 打开登录页，你在页面上完成登录
    3. GET  /v2/plugin/auth/token?state=xxx         轮询取令牌（未完成时服务端返回 11217）
    4. POST /v2/plugin/auth/token/refresh           令牌到期前自动续期
    5. POST /v2/billing/meter/checkin-activity-status  查签到状态
    6. POST /v2/billing/meter/daily-checkin            领取当日积分

  登录态（state）存在服务端，所以在任何地方完成登录，App 轮询都能拿到令牌。
  令牌有效期：accessToken 30 天、refreshToken 60 天。
  只要 60 天内打开过 App，就会自动续期，不用反复登录。
  实测 refreshToken 不轮换，所以手机和电脑可以同时登录同一个账号，互不影响。


【账号与数据安全】
  · 令牌用 Android Keystore 硬件加密后存本机，不落明文、不上传第三方
  · 关闭了 allowBackup，令牌不会随系统备份同步到云端
  · 所有请求直接发往 copilot.tencent.com，不经过任何中转服务


【两个 APK 的区别】
  app-release.apk（推荐）   已签名，约 4.8 MB
    app/build/outputs/apk/release/
  app-debug.apk（调试）     未签名（debug 签名），仅供开发测试
    app/build/outputs/apk/debug/

  升级安装：v1.0 → v1.1 → v1.2 → v1.3 使用同一个签名，可以直接覆盖安装，数据保留。
  （如果之前装的是 debug 包，因签名不同需先卸载再装 release 包。）

  ⚠ 为什么 release 包变大了：v1.3 关闭了 R8 代码压缩。
    v1.2 打开压缩时，Kotlin 标准库的类被降级成包内可见，导致 App 一启动就抛
    IllegalAccessError 闪退（崩溃点在 androidx.startup.InitializationProvider）。
    现在保留混淆会让体积回到 2.6 MB，但需要额外配置 keep 规则，个人工具优先求稳。

【已知限制】
  · 签到接口为逆向所得，WorkBuddy 改版后可能失效，需同步更新
  · 微信登录在 App 内无法闭环（微信小程序登录态不回传），这是微信侧的机制限制
  · 登录页需要联网加载；公司内网/代理可能拦截 copilot.tencent.com
  · 若提示「登录已过期」，长按账号选「重新登录」即可
  · 首次登录若页面一直转圈，多为网络问题，切流量重试一次
